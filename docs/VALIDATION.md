# Compatibility scope

Version 1.0 targets Windows x64 and OBS 31.x, 32.x and 33.x. The cleaned build completed 33 regression checks and isolated single-effect audio, UI and state checks using libobs 31.1.1, 32.2.2 and 33.0.1. Five host languages were covered. Real-use feedback is limited to the author's setup and does not certify other effects or computers.

Native audio processing runs inside OBS. A faulty effect can affect OBS. Saving may need active source audio; failed captures preserve previous state. Long sessions, wider device coverage, DPI/IME/global-hotkey interaction and complete frontend project-save/close workflows are not universally qualified.

The public screenshots were captured from an isolated OBS instance with a fictional empty source setup. No third-party effect was loaded or shown. They demonstrate the NEXUS controls and browser, not audio quality or a vendor compatibility guarantee.
